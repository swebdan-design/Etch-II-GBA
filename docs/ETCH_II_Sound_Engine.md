# ETCH II — Sound Engine

**ETCH II — A Generative Synthesis Machine** · by Synth Centric

Every sound ETCH II makes is computed by the GBA's processor while it plays. There are no recorded samples in the ROM. The only precomputed data are lookup tables generated by `tools/gen_tables.py` (oscillator waveforms, wavetable banks, sine, pitch, filter, envelope and saturation curves).

## 1. Signal path

```
sequencer events ─► voice control (every 24 samples) ─► engine render (24 samples)
                                                        │
                       drive (tanh) ─► bit reduction ─► gain ramp · pan · delay send   (ARM assembly)
                                                        │
      [L, R, SEND] accumulators ─► ping-pong delay (half rate) ─► limiter / master drive ─► 8-bit L/R
```

## 2. Engines

### SUBTRACTIVE — the primary engine

- **Oscillators**: saw, square and triangle read from band-limited tables — 11 octave bands of 1 024 samples, each holding only the harmonics below Nyquist for the top note of its band, with a gentle roll-off (no Gibbs ringing). The band is chosen from the pitch every block, so high notes do not alias. **Pulse** is saw minus a phase-shifted saw (width from B). **Detune** adds a second oscillator.
- **Filter**: Chamberlin state-variable low-pass, Q15 coefficients from a quarter-semitone table, 50 % keyboard tracking. On a resonant BASS (RESO ≥ 6) it runs **2× oversampled**, which keeps it stable up to ~5.4 kHz cutoff with near self-oscillating resonance; elsewhere 1×. The band-pass state is clamped, so nothing can blow up (tested at maximum cutoff, resonance and drive).
- **Envelopes**: amplitude ADSR (linear attack, exponential decay/release, 32 time constants 2 ms–8 s) and a filter envelope (instant attack, exponential decay) scaled by ENVMOD.
- **Accent** (ETCH's model): an accented note sets an accent envelope that adds loudness and filter sweep, its filter decay snaps shorter, and consecutive accents build a "charge" that bleeds away each step.
- **Slide**: the gate stays open; pitch glides exponentially (GLIDE: 4 ms–1.2 s) without restarting envelopes.
- **Drive**: tanh saturation from a 1 024-point table.

### FM 2-OP

Sine carrier, sine modulator (ratios 0.5–13 and √2 for inharmonic tones; carrier 1×, 2×, 3×, 0.5×), modulation index up to ≈ 6 radians from INDEX + envelope + accent, modulator **feedback** (averaged over two samples to tame it). Metallic bass, bells, hollow keys, harsh leads.

### WAVETABLE

Eight original banks — GLASS (sine → bell partials), VOICE (moving vowel formants), METAL (clustered partials), PULSAR (pulse-width sweep), ORGAN (drawbar registrations), DIGIT (sync-like spectra), RUST (gritty, phase-scrambled), HOLLOW (moving notch) — each with 8 frames and 3 mip levels (48 / 16 / 6 harmonics) chosen by pitch. POSITION morphs between adjacent frames by linear crossfade; SPREAD adds a detuned second phase; BRIGHT is a one-pole low-pass.

### PHASE DISTORTION

A cosine read through a warped phase (Casio-CZ principle): SAW and PULSE bend one cycle into two linear segments meeting at a break point set by AMOUNT; SQUARE warps each half-cycle; DOUBLE doubles the warped phase. RESO1 / RESO2 are resonant modes: a cosine at a moving ratio (1–16× the fundamental, from AMOUNT), windowed by a falling saw or a triangle and hard-synced to the fundamental — the filter-like sweep that phase distortion is known for, with no filter. The segment slopes come from a reciprocal table, so there is no division per block.

### RESONATOR

Karplus–Strong: a 1 024-sample delay line read with linear interpolation at a fractional length (fs / f, from a table), a one-pole loop low-pass (BRIGHTNESS) and loop gain (SUSTAIN). Excitation for one period: PLUCK (filtered noise), MALLET (square burst), BOWED (gentle noise for as long as the note is held), GRAIN (sparse noise). Plucked, struck and bowed textures.

### Paraphonic CHORD

The CHORD track is one voice with three oscillators — root and two scale-degree intervals from the chord SHAPE — sharing one envelope, one filter and one output stage, like a paraphonic analogue synth. SUB and WT sum three oscillators inside one loop; FM and PD render three oscillator sets (costlier); RESONATOR plays the root only.

## 3. Procedural percussion

Each of ETCH's four drum lanes keeps its four kit numbers (CORROSION chooses kits per style):

| Lane | Kits |
|---|---|
| KICK | DEEP (long 160 → 44 Hz sweep), PUNCH (fast 330 → 52 Hz + click + low noise), THUD (short, low-passed noise body), CLICK (bright noise transient) |
| SNARE | SHORT (tone + band-passed noise), GRIT (high-passed noise), CLAP (three noise bursts 11 ms apart + tail), RIM (short high tone + metal) |
| CLOSED HAT | CLOSD (metal bank + noise), TICK (very short noise), SHAKE (soft band-passed noise), SHARP (bright metal + noise) |
| OPEN HAT | OPEN (long metal + noise), METAL (ringing ring-modulated tone), BLIP (tonal percussion, rising pitch), CRASH (long noise + metal) |

Components: a sine with an exponential pitch envelope; white noise through a state-variable filter (low-, band- or high-pass); a **metal bank** of three square oscillators at inharmonic ratios combined by XOR (ring modulation) and high-passed; a click; clap re-triggering. VOICING: ANALOG, **FM METAL** (the tone oscillator is frequency-modulated at 1.41×) or **DIGITAL** (bit reduction + hard drive). TUNE, DECAY and LEVEL per lane, TONE (filter brightness) per track; the closed hat chokes the open hat.

**Render cache.** Synthesising four lanes per sample costs up to 150 k cycles per frame, so each hit is synthesised **by the GBA, from its current parameters, into RAM** (int8, normalised) in the main loop, and the audio interrupt plays that render. Three cache entries per lane (least-recently-used) keep two kits ready while a third renders; a project load renders the start pattern's kits before playback. If a parameter has just moved, the last render of the same kit plays until the new one is ready (a few frames). Only a kit that has never been rendered is synthesised live — the same code path, in the interrupt. This is internal synthesis, not sample playback: every render comes from the synthesis code and the current settings, and changes whenever they change (including DRIFT's tuning drift).

## 4. Modulation

- **LFO** per voice: triangle, square, saw, sample & hold (from the voice's own xorshift stream); 0.03–24 Hz; to pitch (± one octave), TONE, amplitude or pan; depth is squared for fine control at low settings.
- **Sound drift** (ETCH's): after each committed evolution the bass TONE and each drum lane's tuning take one small bounded random step (DRIFT ±2 / ±1, CORRODE ±5 / ±2). Never saved; reset in STABLE.

## 5. Effects

| Effect | Where | Notes |
|---|---|---|
| Drive / saturation | per voice, per drum lane, master | tanh table |
| Filtering | SUB, WT, drum noise; delay feedback | SVF / one-pole |
| Delay | one shared bus | tempo-synced 1/16 … 1/2 (incl. dotted 1/8), feedback low-pass, stereo echoes or ping-pong; runs at half rate (≈7.9 kHz), skipped entirely once sends and tail are silent |
| Bit reduction | per voice / lane | sample-and-hold rate reduction + bit masking |
| Stereo placement | per track | near-constant-power pan; hats offset closed-left / open-right |
| Limiter | master | block-peak look-behind, instant attack, slow release; final 8-bit clamp |
